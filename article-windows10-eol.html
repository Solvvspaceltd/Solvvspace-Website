Windows 10 support has ended. What your business should do now

SS
SolvvSpace team
·November 2025 ·5 min read

Microsoft ended support for Windows 10 on 14 October 2025. Since then, Windows 10 machines receive no security updates, no bug fixes and no technical help from Microsoft unless they are enrolled in paid Extended Security Updates. If any device in your organisation still runs it, that device is the easiest way in for an attacker, and it is likely to fail a Cyber Essentials assessment.

What end of support actually means

Your computers did not stop working on 14 October. They still turn on and run your software. What changed is that every vulnerability found since then stays open on those machines for good. For anyone handling customer data, or working toward Cyber Essentials, that is a real liability.

Closing the gap, in order
1

Find every Windows 10 device

Laptops, desktops, the reception PC, the machine that runs the label printer. Intune or a simple inventory script will list them in minutes.

2

Check which can run Windows 11

Windows 11 needs a TPM 2.0 chip and a supported processor. Machines bought before 2018 often fall short. The free PC Health Check tool answers this per device.

3

Upgrade or replace

Upgrade what can be upgraded for free. Budget to replace the rest, starting with machines that hold sensitive data or face the internet.

4

Cover the stragglers

Anything you cannot move straight away should go on Extended Security Updates, or be taken off the network, until it is replaced.

Your options, plainly

  • Upgrade compatible devices to Windows 11. The upgrade itself is free. The cost is the IT time to test your applications and roll it out properly.
  • Replace devices that cannot upgrade. Older hardware is usually slower and costlier to support anyway, so this is a sensible point to refresh it.
  • Buy Extended Security Updates as a bridge. Microsoft sells security updates for Windows 10 business devices for up to three years, priced per device and rising each year. It buys time. It is not a plan.
  • Move work to the cloud. If your team mostly works in a browser and Microsoft 365, cloud based working reduces how much depends on each local machine.

Does this affect Cyber Essentials?

Yes. Cyber Essentials requires every device in scope to run software that is still supported and receiving security updates. An unsupported Windows 10 machine in scope will fail the assessment unless it is covered by Extended Security Updates or removed from scope.

Where to start this week

Run the inventory first. Most organisations find a handful of forgotten machines they did not know were still on Windows 10, and those are exactly the ones that cause trouble.
